Academic Project Methodology

An end-to-end, interpretable machine learning pipeline that prescribes optimal crop candidates based on soil chemistry and environmental climate factors.

🧠 8 Models Evaluated · 5-Fold Stratified CV · Statistical Hypothesis Testing

🎯 Project Objectives

  1. Data Collection & Structured EDA: Collect, clean, and analyze agricultural parameters (N, P, K, pH, temperature, humidity, and rainfall).
  2. Baseline & Multi-Model Training: Establish a naive majority-class baseline and train 6 classification models — Logistic Regression, K-Nearest Neighbors, Decision Tree, Random Forest, Support Vector Machine, and XGBoost.
  3. Rigorous Evaluation & Statistical Validation: Evaluate models using Accuracy, Precision, Recall, F1-scores, 5-fold cross-validation, paired t-tests, and McNemar's tests to confirm statistical significance.
  4. Explainable AI (XAI) Integration: Apply tree feature importance (MDI) and SHAP values so every recommendation is interpretable, presented strictly as model interpretation rather than agronomic causation.
  5. Tuning & Deployment: Hyperparameter-tune and serialize the best-performing model (Random Forest), deploying it via interactive user applications.
  6. Academic Documentation: Complete reproducible, academic-grade documentation and reporting.
